## v0.5.73

### Overview

v0.5.73 is the **canonical v3 convergence** release: `session/3.0` becomes the default workspace writer, `run next` emits a full birth packet, `run brief` returns a `brief-result/3.0` Resume Packet, and the canonical prompts, gates and mirrors now speak the v3 surface. v2 remains fully available as the explicitly labeled legacy branch (workspaces with a stored writer keep their behavior).

**Full Changelog**: https://github.com/catlog22/maestro-flow/compare/v0.5.72...v0.5.73

### Breaking (intentional)

- **Default writer is now `session/3.0`** (`8ffb8b0a`): fresh workspaces negotiate the v3 six-key capability set (`session_run_minimal_v3`/`entity_revision_cas`/`participant_identity`/`request_receipts_v2` true, `execution_lease`/`operation_registry` false, no Execution writes). Existing workspaces keep their stored writer; `maestro config session-schema set session/1.3|session/2.0` remains the legacy escape hatch.
- **Canonical prompts/gates/mirrors v3-ified** (`d278d050`, `4a89ea8d`): run-mode, orchestrator-run-loop, run-mode-lite, ralph, prepare/* and all `.claude/.agents/.codex/.agy` mirrors describe the `session/3.0 + run/3.0` surface; v2 content moved into labeled Legacy branches; the ralph capability gate now requires the v3 six-key exact contract; gate scripts (prompt semantics, run-prompt lint, contract parity, release machine) enforce the v3 tokens and the new default writer.

### Features

- **v3 birth packet** (`8ffb8b0a`): `run next`/`run create` results now carry `run_dir`, `step_id`, `upstream` (from the artifact registry), the guidance snapshot, a knowledge-context handle, `brief.command`, and `run_already_created: true` — replays return the identical packet via the persisted receipt.
- **v3 Resume Packet** (`8ffb8b0a`): `run brief` returns `brief-result/3.0` with the Session summary (`status`, `orchestration_revision`, `objective`, `definition_of_done`, `active_run_ids`), the full Run record, the birth packet fields and a `suggest_only` next hint.

### Fixes

- Release-machine v2 proofs pin explicit `session/1.3` workspaces; built-bin help cases resolve a v2 workspace (`1b99b990`).
- Test fixtures for v2-semantics suites pin the legacy writer explicitly (`a6d3ffef`).
