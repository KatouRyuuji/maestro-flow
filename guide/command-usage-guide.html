核心工作流 14 项（命令 + step）

项目初始化、规划、执行、验证、协调、封存与 overlays。全局入口 /maestro 是智能协调器；analyze/plan/execute/verify/brainstorm/roadmap/blueprint/collab 为一级 step，由编排器经 /maestro 派发，不能直接键入斜杠形态。

/maestro
智能协调器。根据用户意图和项目状态自动选择最优命令链。
/maestro "<intent>" /maestro continue /maestro -y "<intent>" /maestro status
衔接 init→ roadmap→ plan→ execute
/maestro-init
初始化 .workflow/ 目录，创建 state.json、project.md、specs/。项目起点。
/maestro-init /maestro-init --from brainstorm:ANL-xxx
brainstorm→ init→ roadmap
brainstorm 步骤
多角色头脑风暴，产出 guidance-specification.md。可选的初始化前置步骤（step，经 /maestro 派发）。
brainstorm "<topic>"
brainstorm→ init --from
roadmap 步骤
交互式路线图生成。轻量方案，适合需求明确的小型项目（step，经 /maestro 派发）。
roadmap "<desc>" -y
init→ roadmap→ analyze
blueprint 步骤
6 阶段规范蓝图，产出 产品简报 + PRD + 架构文档 + 史诗。适合大型项目（step，经 /maestro 派发）。
blueprint
init→ blueprint→ plan
/maestro-impeccable --chain build
UI 设计原型生成。可选步骤，产出 design-ref/ 和 design tokens。
/maestro-impeccable --chain build
roadmap·→ ui-design→ plan
analyze 步骤
分析阶段。消费 roadmap + project.md，产出 context.md 和 analysis.md。支持多次分析（step，经 /maestro 派发）。
analyze analyze 1 analyze "topic" analyze --gaps ISS-xxx analyze -q "topic"
roadmap→ analyze↻ analyze→ plan
plan 步骤
规划阶段。消费 context.md，产出 plan.json + TASK-*.json。支持 revise 和碰撞检测（step，经 /maestro 派发）。
plan plan 1 plan --gaps plan --dir scratch/xxx
analyze→ plan↻ plan(revise)→ execute
execute 步骤
执行阶段。消费 plan.json，产出代码变更和 .summaries/。逐个 plan 执行，plan 内 wave 并行（step，经 /maestro 派发）。
execute execute --dir scratch/xxx
plan→ execute→ verify
verify 步骤
验证阶段。消费 .summaries/，产出 verification.json。发现 gaps 时回退到 analyze（step，也内聚为 execute 的 E2.7 验证门）。
verify
execute→ verify→ review 或 gaps→analyze
collab 步骤
多 CLI 协作分析。自动或手动选择多个 AI 工具并行分析同一主题（step，经 /maestro 派发）。
collab "<topic>" collab "<topic>" --tools gemini,qwen,claude collab -y "<topic>"
collab→ plan --dir
/maestro-session-seal
封存里程碑：verify 所有 run 完成 → 归档 scratch 到 milestones/ → 推进下一里程碑。
/maestro-session-seal
test→ session-seal→ analyze (next M)
/maestro-overlay
Overlay 管理。创建和管理覆盖层配置，用于临时修改或扩展工作流行为。
/maestro-overlay
/maestro-fork
分支管理。创建工作流分支以并行探索不同方案。
/maestro-fork

质量 7 commands

代码审查、自动测试、UAT、调试、重构、复盘和同步。测试三轨并行：spec/gap/code 智能路由。注：auto-test/review/test/debug/retrospective 已改为一级 step，由编排器通过 session chain 派发，用户经 /maestro-next 或 /maestro "<意图>" 触发，不能直接调用。

auto-test 步骤
统一自动测试。智能路由 spec/gap/code 三轨，CSV 并行写测试 + 诊断迭代。
auto-test --max-iter 5 auto-test --layer L0-L3 auto-test --re-run
verify→ auto-test→ review
review 步骤
分层代码审查。支持 quick/standard/deep 三级深度。自动为 critical/high 发现创建 Issue。
review review --level deep
auto-test→ review→ test
test 步骤
会话式 UAT 验收测试。支持 smoke 模式和 auto-fix 循环。
test test --smoke test --auto-fix
review→ test→ session-seal
debug 步骤
假设驱动调试。科学方法（假设→实验→验证），支持并行假设验证。
debug debug --from-uat {N} debug --parallel
test(失败)→ debug→ plan --gaps
/maestro-odyssey --mode improve
技术债务治理。反思驱动的重构迭代。
/maestro-odyssey --mode improve /maestro-odyssey --mode improve <scope>
maestro kg index
文档同步。代码变更后同步相关文档。
maestro kg index
retrospective 步骤
质量复盘。回顾质量指标和改进机会。
retrospective

主干 Phase 管线

完整的 Milestone 生命周期：分析 → 规划 → 执行 → 验证 → 审查 → 测试 → 审计 → 完成。支持多次 analyze/plan，逐个 execute。

analyze↻ analyze→ plan↻ plan(revise)→ execute→ verify→ review→ test→ session-seal
1
analyze
全量分析当前里程碑，产出 ANL artifact（step）
2
plan
消费 analyze 产出，生成 plan.json + TASK 文件，含碰撞检测
3
execute
逐个 plan 执行，plan 内 wave 并行，产出 EXC artifact
4
verify
验证执行结果。有 gaps 时回退到 analyze
5
review → auto-test → test
质量三件套（编排器派发的 step）：代码审查 → 自动测试 → UAT
6
/maestro-session-seal
封存里程碑：verify 所有 run 完成后归档，推进下一里程碑

五种 Scope 使用模式

每个管线命令支持 4 种 scope，灵活组合分析-规划-执行。

A
analyze → plan → execute → verify
一步到位：默认覆盖里程碑所有 phases
B
analyze 1 → plan 1 → execute 1 analyze 2 → plan 2 → execute 2
逐 Phase：每个 plan 独立执行
C
analyze → plan 1 → execute 1 → plan 2 → execute 2 analyze "hotfix" → plan --dir → execute --dir
混合模式：全量分析 + 逐 phase 执行 + ad-hoc
D
analyze 1 → analyze 2 → plan → execute
统一规划：多次分析后一次规划执行
E
analyze "auth" → plan --dir → execute --dir
纯 scratch：无需 init/roadmap
