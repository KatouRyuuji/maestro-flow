## 核心全景图

```
愿景 / 一号位共识 / 业务目标 / 客户问题
                │
                ▼
        价值流小队 / 超级团队
                │
                ▼
共享上下文:目标 · 规格 · 任务 · 资产 · trace · 复盘
                │
                ▼
AI 工作层:Agent · Skill · workflow · 多 Agent 协调
                │
                ▼
治理层:Owner · 权限 · 审批 · eval · 审计 · 成本
                │
                ▼
        交付物 / 产品变化 / 客户动作
                │
                └──▶ 反馈回写为新规则和新资产
```

---

## 一句话记住

**AI 原生组织不是“人人配一个 AI 工具”,而是把团队改造成一套人和 Agent 共享上下文、低摩擦协作、可审查交付、可持续学习的生产系统。**
