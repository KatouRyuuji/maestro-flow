## v0.5.59

### Overview

本版本把 dashboard 与 docs-site 客户端路由从 `react-router-dom` 迁移到更轻量的 `wouter`（通过本地别名 shim 实现，调用点零改动），为 dashboard 增加可调节面板、右键菜单与 KaTeX 数学公式渲染，并升级了一批核心依赖（`@hono/node-server` 2.x、`@modelcontextprotocol/sdk` 1.30 等）。同时修复了 schema 版本处理，避免 `state.json` 被静默降级。产品统计范围为 `5375fb58..fb551951`，共 3 commits、90 files、+2,283/-1,167；`5375fb58` 是 v0.5.58 发布后的 closure knowhow 补录，不计入产品统计。

**Full Changelog**: https://github.com/catlog22/maestro-flow/compare/v0.5.58...v0.5.59

### Features

**Dashboard 体验增强**
- 新增可调节面板（`react-resizable-panels`），支持自由拖拽布局 (`3ab38e9`)
- 新增右键上下文菜单（`@radix-ui/react-context-menu`） (`3ab38e9`)
- Markdown 支持 KaTeX 数学公式渲染（`rehype-katex` + `remark-math`） (`3ab38e9`)

### Bug Fixes

- 采用向前兼容的 schema 版本处理，防止 `state.json` 被静默降级 (`060b098`)

### Refactors

- 将 dashboard 与 docs-site 客户端路由从 `react-router-dom` 迁移到 `wouter`，通过本地 `src/client/router.tsx` 兼容 shim（vite `resolve.alias` + tsconfig `paths` 别名）实现，移除重型依赖且无需改动任何调用点 (`3ab38e9`)

### Dependency Upgrades

- `@hono/node-server` 1.x → **2.x**（root + dashboard） (`3ab38e9`)
- `@modelcontextprotocol/sdk` 1.27 → **1.30**（root） (`3ab38e9`)
- `hono` → 4.12、`ws` → 8.21、`tsx` → 4.23、`vite` → 6.4（dashboard） (`3ab38e9`)
- `mermaid` → 11.16、`vite` → 6.4（docs-site） (`3ab38e9`)

### Compatibility Notes

- 版本保持 `0.5.x` patch 兼容，**不引入新的 Node.js 要求**：root 仍要求 Node.js `>=22.19.0`，已满足 `@hono/node-server` 2.x（`>=20`）与 `@modelcontextprotocol/sdk` 1.30（`>=18`）的传递性 engines 约束。
- 客户端路由 API 保持不变：`react-router-dom` 的导入经由别名 shim 透明转发到 `wouter`，依赖 dashboard/docs-site 客户端路由的用法无需调整。
- `@hono/node-server` 2.x 为 major 升级；直接使用其底层 server API 的非公开集成应复核 2.x 变更。
