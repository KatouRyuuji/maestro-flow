# v0.5.80

## Highlights

- **Arch-KB templates in search results**: mixed-fusion search now surfaces the bundled Arch-KB architecture templates as scored reference results via a new virtual `template` type — no project-index writes involved.
- **Knowledge-graph explore upgrades (codegraph port)**: opt-in multiplicative relevance-scoring demotion levers (KIND / ISOLATION / PENALTY) plus score-proportional byte-budget allocation with carry-forward and displacement guard, calibrated to Maestro's ~6K–12K explore envelope.

## Fixes

Arch-KB integration hardened after multi-agent review (commit `cee4dfc4`):

- H1: direct-match detection reuses the scorer's `tokenize()` and mirrors its substring/superstring semantics — plural/punctuation queries (`workflows`, `payment,system`, `api.gateway`) are no longer dropped after scoring.
- H2: built-search-adapter mixed provider injects an empty `archKbSearch` stub so bundled templates never leak into the hermetic BUILT_RANKING_GATE baseline.
- M1: merged search results substitute the real query instead of a literal `<query>` placeholder.
- M3: a missing arch-kb index is no longer negative-cached; long-lived processes recover once it appears.
- M4: development-query regex gains ASCII word boundaries (`api` no longer matches `apiary`).
- Equal-score ties now break deterministically by entry id.
