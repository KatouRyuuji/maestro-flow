## v0.5.64

### Overview

v0.5.64 是一次「知识流与 Session/Run 生命周期」体验加固 + 知识图谱基础设施修复的常规补丁发布。主要变更：基于双模型（gpt + qwen）知识流演练与 E2E 演练修复 16 个 UX 摩擦点；为 prompts 面新增三个质量门禁（Staging Quality Bar、frontmatter 质量门禁、Review Presentation Protocol）与会话级知识治理；修复知识图谱代码关系边 / FTS 完整性 / 多语言抽取器；同时修复了 `d41aaed3` 引入的 build 脚本 wasm 拷贝步骤引号错误（本次发布门禁发现并修复）。

**Full Changelog**: https://github.com/catlog22/maestro-flow/compare/v0.5.63...v0.5.64
