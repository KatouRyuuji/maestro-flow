## v0.5.74

### Overview

v0.5.74 hardens the v3 surface after the 0.5.73 convergence: migration can no
longer deadlock on in-flight Runs, `knowledge stage` works against `session/3.0`,
the skill/agent sources are fully v3 (including the run-executor agent and the
Codex/Pi conversion profiles), and new prepublish gates verify the prompt
surface, packaged installs, and the conversion pipeline. The canonical Run
loop remains `session open → run next → execute → run complete --advance →
session complete`; v2 stays available as the labeled legacy branch.

**Full Changelog**: https://github.com/catlog22/maestro-flow/compare/v0.5.73...v0.5.74

### Fixes

- **Migrating a running Run no longer deadlocks** (`638a8d19`): `session migrate --to-v3`
  accepts `running` Runs (projected as `run/3.0 running`; chain step `running`;
  active run bound) and orphaned `running`/`failed` steps with `run_id=null`
  project as `pending` — the v3 face can resume and complete them. E2E verified:
  running Run → migrate → `run brief` (Resume Packet) → `run complete --advance`
  → `session complete`.
- **`knowledge stage` works on `session/3.0`** (`12f9d18a`): the knowledge
  sidecar opens the v3 branch for staging; artifact evidence roots resolve from
  `session.artifacts_ref` through the registry instead of reading the bundle.
- **`--session` overrides stale state.json derivation** (Pi `c02670dc`,
  `0f1f68af`): `requireV3Session` derives the CAS fence from the explicit
  `--session` target; `session unarchive` is a v3 orchestration target and
  `publishPlanV3` replays open/insert as idempotent ("already exists" is a
  success) with stable request ids.
- **Orphaned chain steps no longer block selection** (`83eca935`): execution
  selection prefers the unique non-sealed Execution; a stale sealed
  `current_execution_id` no longer hides the open chain.
- **v2 residue removed from canonical sources** (`2965adba`): run-executor agent,
  skill-iter-tune report phase, and maestro-help now speak only the v3 surface;
  the Codex conversion profile no longer injects `--platform` on `run brief`;
  the executor-boundary lint token now requires "Do not call `maestro run complete`".

### Gate hardening

- `check-session-run-skill-surface.mjs` (`01ae54b0`): 123 command invocations
  cross-validated against the CLI surface + v3 knowledge-stage smoke, wired into
  prepublishOnly.
- `check-session-run-packaged-install.mjs` (`04302457`): packaged-install smoke
  runs in an isolated HOME.
- Legacy multi-generation migration test (`a92c83ac`) and compaction reattach
  test (`9d4e42cf`, `3705adf9`) added to the suite.
